Pinout (ESP-12F): O ESP8266 possui severas restrições no boot (pull-ups mandatórios). A alocação foi desenhada para obedecer a eletrônica e usar o TX/RX para cobrir a falta de pinos.

| Função | Pino | Motivo / Restrição |
| --- | --- | --- |
| **Relé 1** | GPIO 4 | Livre, estável. Seguro para relé ativo baixo. |
| **Relé 2** | GPIO 16 | Não interfere no boot. Seguro para relé ativo baixo. |
| **SDA (I²C)** | GPIO 12 | Livre. Qualquer pino serve (I2C por software no ESP8266). |
| **SCL (I²C)** | GPIO 13 | Livre. Qualquer pino serve (I2C por software no ESP8266). |
| **Encoder A** | GPIO 14 | Aceita interrupção, estável. |
| **Encoder B** | GPIO 3 (RX0) | Aceita interrupção, usar exclusivo como entrada (sem envio pelo PC). |
| **Encoder Botão** | GPIO 0 | Obrigatório HIGH no boot → botão com pull-up para GND funciona perfeito. |
| **Botão Extra 1** | GPIO 2 | Obrigatório HIGH no boot → botão com pull-up para GND seguro. |
| **Botão Extra 2** | GPIO 5 | Livre, pode ser usado como botão normal. |
| **Buzzer** | GPIO 15 | Seguro. Precisa estar LOW no boot, portanto um buzzer ativo ALTO/PWM não apitará no boot. |
| **Serial Debug** | GPIO 1 (TX0) | Continua livre para `Serial.print()`. |

Total: 10 GPIOs (Hardware suprido sem expansores I2C).
